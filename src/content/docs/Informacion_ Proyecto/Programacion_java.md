### Introducción
Esta documentación aborda **el Gestor Documental** desarrollado para la **Asociación Domitila Hernández**, una aplicación de software creada con el objetivo de optimizar, organizar y agilizar la gestión digital de los archivos y procesos operativos de la entidad.

El desarrollo de este programa ha sido posible gracias al **Proyecto de Formación Dual Industrial 2026** de **Femete**, en concreto dentro del itinerario formativo **Programación Java e Inteligencia Artificial**. A través de este marco, se han aplicado tecnologías modernas y herramientas avanzadas para construir una solución informática adaptada a las necesidades reales de la asociación.

A continuación, se presenta toda la documentación necesaria para comprender a fondo el funcionamiento, la estructura y el uso del programa.
